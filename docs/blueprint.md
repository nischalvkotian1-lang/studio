# **App Name**: AttendSync

## Core Features:

- Class Data Input: Users can input total classes conducted and classes they have attended.
- Target Attendance Selection: Allows selection of a target attendance percentage (e.g., 75%, 85%) to base calculations on.
- Real-time Attendance Calculation: Calculates and displays the current attendance percentage immediately after input.
- Attendance Insight Calculation: Calculates and displays how many classes can be safely missed (bunked) and how many classes must be attended to meet or recover target attendance.
- Dynamic Motivational Warnings: A generative AI tool provides contextual motivational warnings or encouraging messages based on the user's attendance status.
- Visual Result Cards: Presents calculation results, insights, and warnings in clean, distinct cards with color indicators (green, yellow, red) for quick status assessment.
- Responsive Interface: A mobile-first, simple, and student-friendly user interface that adapts seamlessly to various screen sizes for optimal usability.

## Style Guidelines:

- Primary Color: Energetic electric blue (#2894F3), inspired by modern productivity apps, provides vibrancy against a dark theme.
- Background Color: A deep, subtly bluish black (#20262C) for a premium and dark modern design.
- Accent Color: A luminous aqua-cyan (#94E7EE) used sparingly for highlights and interactive elements, offering contrast to the primary blue.
- Body and Headline Font: 'Inter' (sans-serif) for its modern, legible, and objective aesthetic, ensuring clear readability in a productivity tool.
- Utilize clean, minimalist icons for input fields and navigation. Implement distinct green, yellow, and red color indicators within result cards to signify attendance status.
- Adopt a mobile-first responsive layout with clearly delineated, clean result cards to enhance readability and user focus across devices.
- Incorporate subtle and smooth animations for transitions, data updates, and user interactions to create a fluid and engaging user experience.
